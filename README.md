# My Torch Helper

**A simple script for helping prototype PyTorch models.**

## Introduction

This is a simple single-file library for helping create PyTorch models quickly with less boilerplate.
It's heavily inspired by [Burn](https://burn.dev) and includes a TUI dashboard with fancy graphs and custom metrics.

For a quickstart, look at the [Example](example.py).

## Required Packages

- `torch`
- `textual`
- `textual_plotext`
